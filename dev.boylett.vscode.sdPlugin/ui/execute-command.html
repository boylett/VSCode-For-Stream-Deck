Finding a command ID

In VS Code open File › Preferences › Keyboard Shortcuts, find the command you want, right-click it and choose Copy Command ID.

Examples

  • workbench.action.tasks.runTask — run a configured task
  • editor.action.formatDocument — format the current file
  • workbench.action.files.saveAll — save every open file
